# 地域別最低賃金 2026（令和8年度）47都道府県データ

日本の**地域別最低賃金**を、**令和8年度（2026年度）**と令和7年度（2025年度）の2年度ぶん、**47都道府県**すべて、機械可読な JSON で公開するリポジトリです。

ただの金額一覧ではありません。各県の**発効日（適用開始日）**と「その発効日が公示上まだ"予定"なのか確定しているのか」まで持っているのが違いで、**「今日時点でこの県は新額が適用中か、それ前年度額か」をプログラムから判定できます**。地域別最低賃金は毎年、答申から実際に適用されるまで都道府県ごとに 2か月以上の開きがあるため、金額だけのデータはすぐ使えなくなります。

- 対象：地域別最低賃金（時給・円）／47都道府県
- 年度：令和8年度（2026年度）確定額 ＋ 令和7年度（2025年度）額 ＋ 引上げ額
- このファイルの組立日：2026-10-22
- 全国加重平均：1,177 円（令和7年度 1,121 円）
- 最高：東京都 1,280 円／最低：宮崎県 1,085 円／差：195 円

## 使い方

### JavaScript で読む（GitHub Pages 経由）

```js
fetch('https://<あなたのID>.github.io/japan-minimum-wage-2026/data/r8-2026.json')
  .then(function (r) { return r.json(); })
  .then(function (d) {
    var t = d.prefectures.find(function (p) { return p.slug === 'tokyo'; });
    console.log(t.amountR8, t.effectiveDate, t.applied); // 1280, '2026-10-01', true
  });
```

### curl

```sh
curl -sL https://<あなたのID>.github.io/japan-minimum-wage-2026/data/r8-2026.json -o r8-2026.json
```

### スプレッドシートに落とす

`prefectures` は必ず同じ11フィールドの配列なので、1行目をヘッダーにすれば表になります。`code` は JIS X 0401（01＝北海道〜47＝沖縄県）で、他サイトの都道府県データと結合しやすいです。

## 各フィールドの意味

| フィールド | 型 | 意味 |
|---|---|---|
| `code` | string | JIS X 0401 の都道府県コード（`01`〜`47`、2桁文字列） |
| `name` | string | 都道府県名（例：`東京都`） |
| `slug` | string | ローマ字の県識別子（例：`tokyo`）。他データとの突合用 |
| `region` | enum | 8区分の地方（`kanto` など） |
| `amountR8` | integer | **令和8年度（2026年度）地域別最低賃金**（円／時間額） |
| `amountR7` | integer | 令和7年度（2025年度）の額（円／時間額） |
| `diff` | integer | `amountR8 - amountR7`（引上げ額） |
| `effectiveDate` | date | その都道府県で新額が**適用開始日**（`YYYY-MM-DD`） |
| `dateTentative` | boolean | `true`＝公示上、発効日がまだ「予定」。金額は確定でも日付が未確定な県があります |
| `applied` | boolean | `true`＝2026-10-22 時点で発効日を迎えている（＝新額が適用中） |

## 扱うときの注意

- **公式の代替ではありません。**地域別最低賃金は各都道府県労働局が公示し、公示から適用までに時間があります。金額・発効日は必ず労働局の公示で確認してください。
- **特定（産業別）最低賃金は含まれていません。**一部の業種では地域別より高い額が定められており、その業種では本データの金額が適用下限とは限りません。
- `applied` は「その年度の額が今使えるか」のフラグです。年度が切り替わると意味が変わるので、再利用時は必ず `updatedAt` を見てください。
- 本データには**全国順位は入れていません**（順位は並び替えるだけで出せるため、持つと更新時にズレます）。

## 更新方針

- 労働局の公示変更（金額・発効日）が出て次第、`updatedAt` を上げて更新
- 令和9年度（2027年度）は、答申→公示の時期に `data/r9-2027.json` を追加予定
- `schema.json` のフィールドは増やしても減らさない（既存の利用側を壊さない）
